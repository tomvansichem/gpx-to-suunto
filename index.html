    From any planner to your wrist

    1. Export the GPX

      Get the route out of wherever you planned it. Strava and Komoot both offer this on the route page: look for Export or Download, then pick GPX.

      Garmin Connect, RideWithGPS and most race websites have a GPX export too. Tracks and routes both work.

    2. Convert it here

      Choose the file at the top of this page. Every turn is found and written into the file as a Suunto turn waypoint.

      Check the map, then tap Download Suunto GPX.

    3. Import it into Suunto

      Import the downloaded file in the Suunto Routeplanner and save the route. Open it in the Suunto app and switch on turn-by-turn.

      No turn-by-turn option? Rebuild the file with “Start, end and every turn” under Adjust turn detection.

    Questions

    Why does my route have no turn-by-turn in Suunto?

    Turn-by-turn needs turn waypoints in the file. Routes you plan in Suunto get them automatically. GPX files from Strava, Komoot and most other planners only contain the line itself. This tool adds the waypoints in the same format Suunto's own route planner uses.

    Is my file uploaded anywhere?

    No. The file is read and converted in your browser, on your device. Once the page has loaded you can switch off wifi and it still works. The source code is on GitHub if you want to check.

    Which Suunto watches does it work with?

    It writes the same kind of file as Suunto's own route planner, so it should work on any watch that gives turn-by-turn for routes planned in Suunto. It has only been tried on one watch, though. This is a free tool, offered as is: there is no support and no promise that it works with yours.

    I get too many or too few turns

    Open Adjust turn detection below the route. Raise the minimum turn angle to drop gentle bends, or raise the look-around distance if a twisty trail or GPS wobble creates turns that aren't there. The map and the list update as you type.

    The elevation profile on my watch is flat

    Then the original file has no elevation data. The tool keeps whatever elevation is in the file but can't add it. You'll see a warning when that's the case.

    Is this an official Suunto tool?

    No. It's an independent, free tool and isn't affiliated with or endorsed by Suunto.
